# Cel Shift art direction

## North star

Midcreek must read immediately as a bright, working liquid-cooled data hall:
white racks, polished concrete, yellow containment kerbs, black coolant hose
loops, tiered overhead trays, real PPE, and small technicians inside a large
system.

Cel Shift adds:

- Two-tone hard-terminator shading
- Crisp controlled outlines
- Cool sky-bounce blue in shadows
- Bright, clean color without grunge or murk
- Shape-coded status readable independently of color

## Non-negotiable scene language

- Back-to-back rack-row pairs create alternating narrow service and wide cold
  aisles.
- Coolant hoses hang only on rack backs in service aisles.
- Faults use a red exclamation badge; active work uses a blue wrench badge.
- The technician remains visibly shorter than a 2.10 m rack.
- The HUD is part of the game frame, not an afterthought.

## Public-source boundary

This repository contains only selected generated concept renders and rewritten
art-direction guidance. It must never import private Atlanta reference
photography, source prompts containing private context, or unreviewed metadata
from `midcreek-concept`.
